# Code of Conduct

**English** | [简体中文](CODE_OF_CONDUCT.md)

## In one line

Be kind to people, be strict about the work.

## Scope

This applies everywhere the project lives — issues, pull requests, code review, commit messages,
discussions — and to anything said publicly on behalf of this project elsewhere.

## What we expect

- **Address the work, not the person.** Criticise the code, the design, the docs; not whoever wrote them.
- **Assume good faith.** In text it is easy to read "why is this written this way?" as an attack.
  Assume it was not meant that way, and ask before concluding.
- **Accept disagreement.** Technical disagreement is normal. Bring reasons and evidence. Being
  convinced is fine; not being convinced is also fine.
- **Make room for newcomers.** Everyone opened a first pull request once. When you point out a
  problem, try to say how to fix it.
- **Respect the maintainer's time.** This is a side project; replies may be slow. Nudging is fine,
  understanding is appreciated.

## What is not acceptable

- Personal attacks, insults, demeaning remarks
- Discriminatory language based on gender, sexual orientation, disability, appearance, body size,
  race, ethnicity, age, religion, or nationality
- Harassment of any kind, including unwelcome private contact
- Publishing others' private information without consent (address, legal name, private email, …)
- Sexualised language or imagery
- Sustained disruption of discussion, spam, deliberate trolling

## Reporting

If you experience or witness a breach, reach the maintainer
([@jxwine](https://github.com/jxwine)) either way:

- **Email jxwu0099@gmail.com** — use this when it involves a specific person, or anything you
  would rather not post publicly
- Or open an issue — fine for anything that can be discussed in the open

Every report is taken seriously. The maintainer will protect the reporter's privacy and will not
disclose their identity without consent.

## Enforcement

The maintainer may remove, edit, or reject any comment, commit, code, or issue that breaches this
document, and will say why.

Depending on severity:

1. **A private word** — explaining the problem and asking for a change
2. **A public warning** — stated in the thread, with a request to stop
3. **A temporary restriction** — participation declined for a period
4. **A permanent ban** — for severe or repeated breaches

## About this document

This is a **short, self-written** code of conduct, not a translation of the
[Contributor Covenant](https://www.contributor-covenant.org/). If you would rather this project
adopted that widely used standard text, open an issue and say so.
